# 结果页排版修复

## 1. 字体与字重回归设计稿
统一使用项目既有的字号层级，拉开主次差距：

- 人格标题（奶油小绅士）32px / bold，MBTI 18px / semibold 次级紫
- 人格金句 18px / medium，行高 1.65
- 模块标题（小世界 / 原来它是这样的猫 / 情感卡）20px / bold
- 卡片标题 16px / semibold，说明文字 14px / regular，颜色降一档
- 关键词 chip 13px / medium

去掉当前多处 15px/17px/19px 混用的中间层级，只保留 32 / 20 / 18 / 16 / 14 / 13 六档。

## 2. 「小世界」改成明信片式布局（附件1）
当前是三张等宽竖图 + 图下文字，信息散。改为明信片卡：

```text
┌───────────────────────────────┐
│ ┌────────┐  靠窗发呆          │
│ │  图片  │  我喜欢你在，      │
│ │ 4:5    │  但不用一直陪我。  │
│ └────────┘         01 / 03    │
└───────────────────────────────┘
```

- 横向滑动的整卡（宽度约 88% 屏宽），奶油白玻璃底 + 24px 圆角 + 柔光阴影
- 左侧图片圆角 18px，右侧标题 + 台词竖排，底部右下角淡色序号
- 卡片下方保留小圆点分页指示

## 3. 修复情感卡文字被截断（附件2）
「在糯米团眼里，你是什么？」当前一行硬撑导致右侧被裁。

- 标题容器加 `min-w-0` + 允许换行，去掉 leading-none
- 猫名较长时自动折行，字号 17px、行高 1.5
- emoji 与文字用 flex + items-start 对齐，避免基线挤压
- 卡片左右内边距统一 20px，右侧留出安全间距
