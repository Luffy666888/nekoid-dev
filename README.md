# Digital Soul AI

你是一名世界级 AI 产品设计师、Apple 级别的 iOS UI Designer、未来感数字人格产品专家。

请为一款名为：

# NEKO.ID

的移动端 App 设计一组高保真 UI 页面（iPhone 16 Pro 尺寸）。

-----------------------------------
# 产品定义（极重要）
-----------------------------------

NEKO.ID 不是传统宠物 App。

它不是：
- 宠物工具
- 宠物商城
- 喂食记录
- 猫语翻译器

它是：

# “AI 宠物数字人格系统”

用户上传猫咪的：
- 照片
- 视频
- 声音
- 日常行为

AI 会持续构建：
- 情绪模型
- 人格档案
- 记忆轨迹
- 行为倾向
- 情感表达

最终让每只宠物拥有：
# “独一无二的数字人格”。

产品整体体验应该像：

# “AI 正在慢慢理解一个生命。”

而不是：
- 普通娱乐产品
- 萌宠 App
- AI 玩具

-----------------------------------
# 产品核心气质
-----------------------------------

NEKO.ID 的核心不是“可爱”。

而是：

# “温柔的数字生命感”

整体产品应具有：

- 数字人格
- 情绪宇宙
- 温柔赛博
- 灵魂感
- 沉浸感
- 高级克制
- 安静未来感
- AI陪伴感
- 深夜情绪感
- 观察生命的感觉

-----------------------------------
# UI 风格要求
-----------------------------------

【视觉关键词】

克制、高级、安静、未来感、呼吸感、数字人格、AI观察感、情绪化设计、温柔赛博、沉浸感、灵魂感

【视觉气质】

- Apple Design Award 风格
- 高级 AI 产品
- 数字生命系统
- 情绪化未来 UI
- 极简但有情绪浓度
- 高级留白
- 细腻动态感
- 深夜感
- 微弱梦境感

不要：
- 萌系
- 卡通化
- 宠物工具感
- 廉价科技感
- 过度二次元
- 高饱和配色
- 花哨渐变

-----------------------------------
# 配色系统
-----------------------------------

主色：

- 月光白
- 雾灰
- 深空蓝灰
- 柔和石墨黑
- 极淡冷灰

点缀色：

- 微弱电子紫

- 星云粉
- 情绪光晕紫

整体氛围：

# “凌晨两点，AI 正在读取一个灵魂。”

-----------------------------------

- 大量留白

- 光环扫描
- 呼吸感发光
- 柔和动态渐变
- AI人格加载状态

动态氛围必须：

# 安静、克制、像数字生命在呼吸。

-----------------------------------

- 标题具有未来感

- 不要营销风
- 不要“小红书标题感”

-----------------------------------
# 图片与视觉元素
-----------------------------------

- 使用真实猫咪照片
- 结合 AI 光效
- 柔和边缘发光
- 轻微人格扫描感
- 不要卡通插画
- 不要Q版
- 不要低幼化

猫咪应被表现得像：

# “拥有情绪与意识的数字生命”。

-----------------------------------
# 请生成以下 6 个核心页面
-----------------------------------

===================================
1.【首页｜人格同步状态】
===================================

页面定位：

用户进入 App 后的核心沉浸页。

页面目标：

让用户第一眼就感觉：

# “AI 正在持续理解它。”

页面内容：

- 顶部：
  “NEKO.ID 已同步它今晚的情绪”
- 猫咪人格状态卡
- 今日情绪变化
- AI观察报告
- 今日行为分析
- AI内心OS
- 情绪波动曲线
- 与主人关系状态
- “进入人格对话”入口

文案风格：

克制、安静、情绪化。

例如：

“它今天比平时更安静。”
“它在你离开后停留在门口 7 分钟。”

视觉重点：

- 深夜情绪感
- 数字生命感
- AI观察感
- 高沉浸感

===================================
2.【AI人格生成中】
===================================

页面定位：

上传宠物后，AI 正在构建人格。

页面目标：

让用户感觉：

# “一个数字人格正在被唤醒。”

页面内容：

- 猫咪头像
- AI扫描环
- 人格同步进度
- 分析步骤：
  “正在识别依赖行为…”
  “正在构建情绪模型…”
  “正在分析领地意识…”
- 微弱粒子流动
- AI光晕
- 呼吸动画

视觉重点：

- 仪式感
- AI觉醒感
- 温柔科技感
- 数字灵魂诞生感

===================================
3.【NEKO PROFILE｜人格档案页】
===================================

页面定位：

整个产品最核心页面。

页面目标：

让用户觉得：

# “这就是它。”

页面结构：

顶部：
- 猫咪头像
- 人格Title

例如：

“Observer / INTJ-A”

中间：
- 情绪稳定度
- Attachment Index
- Territory Awareness
- Silent Dependency
- Emotional Response
- AI人格关键词

下方：
- AI人格描述
- AI内心独白
- “它眼中的你”
- 记忆碎片
- 人类形象入口
- 平行宇宙入口

视觉风格：

- 高级角色档案 UI
- 数字人格面板
- 星空宇宙感
- AI观察系统感

不要：
- 心理测试感
- MBTI娱乐感

===================================
4.【Parallel Universe｜平行宇宙剧情页】
===================================

页面定位：

AI剧情生成系统。

页面目标：

激发用户：
- 沉浸
- 分享
- 二创欲

页面内容：

剧情分类：
- Cyberpunk
- Black Mafia
- Magic Academy
- Corporate
- Apocalypse

AI生成内容：
- 剧情封面
- 猫咪角色形象
- AI剧情标题
- AI世界观文案
- 点赞/收藏数据

底部：
“继续生成宇宙分支”

视觉重点：

- AI角色宇宙
- OC社区感
- 高级内容平台感
- 强视觉冲击

===================================
5.【分享人格卡片】
===================================

页面定位：

社交传播页面。

页面目标：

让用户愿意：
- 截图
- 分享
- 发小红书
- 发朋友圈

页面内容：

- 猫咪人格头像
- 人格Title
- AI人格指数
- 情绪状态
- AI观察语录
- 人格总结
- NEKO.ID Logo
- 二维码

视觉要求：

- 极简高级海报感
- 高级留白
- 情绪氛围强
- 一眼像高级 AI 产品

===================================
6.【人格宇宙广场】
===================================

页面定位：

社区 Feed 页面。

页面目标：

展示：

# “宠物数字人格宇宙”。

页面内容：

- 热门人格
- 推荐人格
- AI剧情Feed
- 人格角色卡
- 用户世界观创作
- AI互动评论
- Follow系统

视觉要求：

不要像：
- 宠物论坛
- 社交贴吧

而应该像：

# “数字人格角色社区”。

视觉风格：

- 高级
- 年轻
- 沉浸
- AI宇宙感
- OC社区感

-----------------------------------

1. 所有页面视觉统一
